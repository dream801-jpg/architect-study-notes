단면 답안의 구성과 시간

단면설계 / PDF 페이지 순서 기준

핵심 개념

단면·입면·마감·설비·상세·주기를 함께 작성한다.

필기 정리 · 자세히 읽기
  • 단면문제: 단면 + 입면 + 마감(단열, 방수) + 설비 + 상세 + (주기) → 2시간 10분.
  • 지문을 보고 외부·내부 입면을 구분한다. 필요 없는 것은 그리지 않기.
  • 마감은 두께 있는 것 위주로.
  • 가능하면 글씨 박스. 예시로 room(실명)이라는 글씨를 박스 안팎에 적었다.
  • 상세: 시간이 없으니 그냥 뻥튀기하여 표현 + 상세 치수.
  • GL과 FL이 서로 다른 경우 유의.

⭐ 중요 암기

원본 별표: 지문을 보고 필요한 내·외부 입면을 구분하기.

⚠️ 주의 / 헷갈리는 내용

“뻥튀기”는 상세를 확대해서 표현하라는 수업 표현으로 정리했다. 상세 치수를 함께 적는다.

공식 / 수치 / 기준 · 원본값

2시간 10분: 단면 과제 풀이 시간에 관한 원본 메모. 교시 전체 시험시간과 구분.

층고의 구성요소

단면설계 / PDF 페이지 순서 기준

핵심 개념

층고를 구조·설비 공간과 반자높이로 나누어 본다.

필기 정리 · 자세히 읽기
  • 별표: 층고 구성요소.
  • 윗부분부터 보춤, 설비공간, 반자높이를 화살표로 구분한 단면 스케치. 보 하부가 일부 내려오는 형상과 점선이 있다.
  • 층고가 제시되지 않을 경우 각 층에 맞게 정한다는 메모.
  • 대부분 RC, S조는 잘 안 나옴.
  • 가끔 지붕평면도가 같이 나옴.

⭐ 중요 암기

원본 별표: 층고 구성요소.

⚠️ 주의 / 헷갈리는 내용

RC·S조와 지붕평면도에 대한 빈도 표현은 개인 필기다. 출제 통계로 바꾸지 않았다.

보충 설명 / 검토 의견 · 원본과 구분

보충 설명: 새 도식은 층고 안에서 보춤·설비 공간·반자높이의 위치 관계를 보여 주는 개념도다. 슬래브·마감 두께 등은 원본에 수치가 없어 임의로 더하지 않았다.

하중 전달·기초·동결선

단면설계 / PDF 페이지 순서 기준

핵심 개념

골조와 벽식의 하중 전달 흐름을 구분한다.

필기 정리 · 자세히 읽기
  • 구조 평면: 기둥(C), 작은보(B), 큰보(G), Slab.
  • 라멘조 하중 전달: 바닥 → 작은보 → 큰보 → 기둥 → 기초 → 지반.
  • 벽식 하중 전달: 바닥 → 내력벽 → 기초 → 지반.
  • ⭐ 지하층이 있을 때 온통기초라는 수업 메모.
  • ⭐ 동결선: 겨울철 땅이 어는 깊이, 지역마다 다름.
  • 동결선은 문제에서 언급하지 않으면 쓰지 않아도 된다. 필기에는 그냥 주는 것으로 적어 놓았음.
  • 중부 기준 900~1000mm. 기초도 비슷한 높이라는 메모.
  • 칸막이벽이라고 나오면 얇은 선.

⭐ 중요 암기

원본 별표: 지하층과 온통기초, 동결선.

⚠️ 주의 / 헷갈리는 내용

지하층이 있을 때 온통기초, 동결선 900~1000mm는 이 수업의 계획 메모다. 실제 기초 형식·동결 깊이는 지문·지역·지반 조건에 맞춰 확인한다.

공식 / 수치 / 기준 · 원본값

동결선 중부 기준: 900~1000mm(수업 메모).

액세스 플로어·창문·창턱

단면설계 / PDF 페이지 순서 기준

핵심 개념

단면에서 바닥 높이와 창의 입면·치수를 함께 표현한다.

필기 정리 · 자세히 읽기
  • Access Floor: Slab down하여 바닥 높이 맞추기.
  • ⭐ 단면에서는 평면과 달리 창문을 반드시 표현한다.
  • 창문 단면의 선은 얇게.
  • 반자와 레벨 맞춤.
  • 개폐형 창의 단면 예시: 아래쪽 개폐되는 창 900, 위쪽 고정유리(FIX) 1200.
  • 창턱높이(바닥에서 창 하단까지) 메모: 750~900 / 로비·홀 300~ / 화장실 1500~.

⭐ 중요 암기

원본 별표와 “무조건”: 단면에 창문 표현을 빠뜨리지 않기.

⚠️ 주의 / 헷갈리는 내용

900과 1200은 같은 부분의 대안값이 아니다. 개폐창과 그 위 고정유리의 서로 다른 부분을 가리킨다.

공식 / 수치 / 기준 · 원본값

개폐창 900 / 그 위 고정유리 1200. 창턱높이: 일반 750~900 / 로비·홀 300~ / 화장실 1500~(원본 단위 생략).

치수와 계단·난간

단면설계 / PDF 페이지 순서 기준

핵심 개념

치수를 안쪽·바깥쪽으로 나누고 계단의 단과 난간을 함께 그린다.

필기 정리 · 자세히 읽기
  • ⭐ 치수: 위쪽은 그리드 치수·전체 치수만.
  • 왼쪽은 GL 기준. GL~파라펫 위, GL~기초 아래.
  • 기초 두께, GL에 맞춰 1층 FL, 각 층고. 여유가 있으면 창 높이 치수.
  • ⭐ 계단+난간: 단너비 280~300, 단높이 150~180.
  • 난간 높이 1200.
  • 난간 양 끝은 150씩 여유를 두고 손잡이를 그린다.

⭐ 중요 암기

원본 별표: 치수, 계단+난간.

⚠️ 주의 / 헷갈리는 내용

이 범위는 필기의 설계 메모다. 건축물 용도별 법정 최소·최대 치수로 확정하지 않는다. GL(지표면)과 FL(바닥면)의 기준을 구분한다.

공식 / 수치 / 기준 · 원본값

단너비 280~300 / 단높이 150~180 / 난간 높이 1200 / 손잡이 양 끝 여유 150씩(수업 작도 메모).

난간과 축척별 재료 해치 비교

단면설계 / PDF 페이지 순서 기준

핵심 개념

난간 작도 메모와 재료별 1/100 도면·상세도의 표현 차이를 구분한다.

필기 정리 · 자세히 읽기
  • 난간 높이 약 1200, 난간 손잡이 약 800~900은 수업에서 설명한 작도용 대략 수치다.
  • 난간은 등간격 선으로 3개만 표현한다는 작도 메모. 손스침과 양 끝 기둥은 두 선, 나머지는 단선으로 그린다.
  • ⭐ 재료의 상세표현 표는 같은 재료를 축척에 따라 어떻게 다르게 그리는지 비교한 것이다. 윗행은 1/100 도면, 아랫행은 상세도다. 상세도 자체의 축척 숫자는 원본에 적혀 있지 않다.
  • 벽돌: 1/100에서는 사선으로 간략히 채운다. 상세에서는 벽돌 줄눈을 나누고 사선을 함께 표현한다. 원본 메모: “벽돌그림”.
  • 블록(원문: 블럭): 1/100에서는 교차 사선으로 표현한다. 상세에서는 블록의 구획과 빈 부분이 드러나는 모양을 그린다. 기존 정리의 “목재·나뭇결” 판독을 바로잡았다.
  • 석재: 1/100에서는 두 경계선 사이에 점을 간략히 찍는다. 상세에서는 불규칙한 각진 조각과 점을 함께 표현한다.
  • 몰탈: 1/100에서는 두 경계선으로 간략히 표현한다. 상세에서는 그 사이에 점을 채운다.
  • 자갈: 1/100에서는 두 경계선으로 간략히 표현한다. 상세에서는 크기가 다른 알갱이를 그린다.
  • 철근콘크리트: 1/100에서는 두 경계선 사이를 사선으로 표현한다. 상세에서는 알갱이·점과 짧은 사선을 조합한다. 원본 스케치를 특정 배근 상세로 확장하지 않는다.
  • 아래쪽 표도 1/100과 상세를 비교한다. 항목은 와이어메시, 단열재, 지반이다.
  • 와이어메시: 1/100 칸에는 X가 적혀 있고, 상세 칸에는 끊긴 선 위에 X가 반복된다. X를 해치 무늬 전체로 반복해서 채우지 않는다.
  • 단열재: 1/100 칸에는 물결형과 사선형 두 예시가 표시되어 있다. 상세 칸에는 두 경계선 사이에 연속 물결형을 그렸다.
  • 지반: 1/100에서는 굵은 수평선으로 간략히 표현한다. 상세에서는 지면 아래에 방향을 달리한 사선 묶음을 그렸다.

⭐ 중요 암기

⭐ 재료 해치는 1/100 도면의 간략 표현과 상세도의 표현을 구분해서 익힌다. 같은 재료라도 두 칸의 무늬가 다르다.

⚠️ 주의 / 헷갈리는 내용

난간 자체의 높이와 손잡이 높이는 구분한다. 여기의 수치는 작도 설명에서 쓴 대략값으로, 법규의 허용 오차를 뜻하지 않는다. 재료 표는 수업 필기의 표현 예시로 보존하며 모든 도면에 적용되는 공통 해치 규정으로 확대하지 않는다. 상세도에 임의의 축척을 붙이지 않는다.

공식 / 수치 / 기준 · 원본값

난간 약 1200 / 손잡이 약 800~900: 작도용 대략값. 재료표의 간략 표현은 1/100이며 상세도의 축척 숫자는 기재되지 않았다.

시험 포인트 · 원본 강조와 메모 기준

원본의 별표가 붙은 재료 표현 표를 기준으로, 같은 재료를 1/100 도면과 상세도에서 각각 어떻게 표현하는지 비교한다.

개인 메모

원본 “벽돌그림” 메모 보존. 사용자 확인: 1/100일 때와 상세도일 때를 구분한 표.

보충 설명 / 검토 의견 · 원본과 구분

확인 보충: 피난·방화구조 규칙 제15조에서 규정한 해당 계단의 손잡이 높이는 85cm다. 수업의 개략 작도값과 법규 확인값은 구분해 둔다. 국가법령정보센터 · 피난·방화구조 규칙 제15조

필기 정리 · 자세히 읽기
  • 평면에서 계단의 수는 선의 개수로 세고, 단수는 선의 개수−1로 센다는 수업 기준.
  • 해당 작은 예: 선 3개 → 단수 2개. 선 사이 디딤 구간 2개를 구분한다.
  • 계단참 깊이 > 계단 폭이라는 수업 메모.
  • ⭐ Headroom: 계단참 아래 머리 위 공간. 원본에 2.1 표시.
  • 계단의 수직 두께도 고려.

⭐ 중요 암기

원본 별표: Headroom.

⚠️ 주의 / 헷갈리는 내용

이 필기는 평면 표현에서 선과 사이 구간을 세는 기준이다. 전체 층고로 단높이를 산정할 때의 계단 시작·끝 바닥면은 따로 맞춘다.

코어형 계단과 특별피난계단

계단설계 / PDF 페이지 순서 기준

핵심 개념

계단과 코어의 배치를 분리해 검토한다.

필기 정리 · 자세히 읽기
  • 코어형 계단: 코어를 붙이지 말고 분리해야 한다는 수업 메모. 특별피난계단.
  • 폭이 충분한 경우와 충분하지 않은 경우의 배치를 비교한 스케치.
  • 사용자 기억: X자로 표시한 작은 구획은 샤프트 같은 설비 공간이고, 배연설비를 설명한 그림이었던 것 같음.
  • ⭐ 가운데 홀을 외기에 면하게 할 때 동선이 좋아야 한다.
  • 모든 수평구간에 레벨을 표기한다.

⭐ 중요 암기

원본 별표: 홀을 외기에 면하게 하는 경우의 동선.

⚠️ 주의 / 헷갈리는 내용

제연은 연기를 제어하는 개념이고, 특별피난계단 부속실에서는 외기를 공급해 연기 유입을 막는 방식이 있다. “연기를 빼내는 배연”과 구분하되 법령의 배연설비 표현도 함께 확인한다.

확인 필요 사항

[확인 필요: 10쪽 X자 구획] 제연용 급기풍도일 가능성은 있으나 원본 실명·범례가 없어 해당 샤프트의 용도는 미확정.

보충 설명 / 검토 의견 · 원본과 구분

조사 보충: 특별피난계단의 계단실·부속실에는 제연설비 기준(NFTC 501A)이 적용된다. 부속실에 외기를 공급해 압력을 높이고 연기가 들어오지 않게 하는 급기가압 방식에서 급기풍도(샤프트)를 사용할 수 있다.

다만 건축물 설비기준 규칙 제14조제2항도 특별피난계단 등의 “배연설비”를 규정하며, 제7호는 급기가압 또는 급·배기 방식의 경우 소방관계법령에 따르도록 한다. 따라서 특별피난계단 옆이라고 해서 “배연은 틀리고 제연만 맞다”고 단정하지 않는다.

이 스케치는 특별피난계단과 붙은 설비 구획이라는 맥락상 제연용 급기 샤프트 가능성이 있다. 이는 추정이다. X자 기호 하나만으로 급기·배출·다른 설비 샤프트를 특정할 수 없으므로 도면의 실명·범례·공기 흐름을 확인해야 한다. 국가법령정보센터 · NFTC 501A · 국가법령정보센터 · 건축물 설비기준 규칙 제14조 · 소방본부 · 특별피난계단 제연설비 교육자료(방식 설명 참고)

핵심 개념

구조 프레임과 부재 목록을 만들고 코어·경간을 함께 검토한다.

필기 정리 · 자세히 읽기
  • RC / S(일반, 경량).
  • 구조프레임 + 부재 리스트 + 상세 + (주차계획).
  • 코어 위치 스케치.
  • 횡력에 의한 비틀림에 저항할 때라는 취지의 메모와 “기둥 << 내력벽”.
  • RC: 6~8m span, Max 12m.
  • S 일반: 8~12m, Max 18m.
  • 가로·세로 둘 다 Max로 계획 X.
  • 사용자 확인: 기둥과 내력벽의 횡력 저항 비교, RC·S의 경간 범위는 일반적인 경우를 비교한 수업 설명.

⚠️ 주의 / 헷갈리는 내용

공식 / 수치 / 기준 · 원본값

원문 경간: RC 6~8m / Max 12m, S 일반 8~12m / Max 18m.
